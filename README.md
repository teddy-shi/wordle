Wordle Widget Remake
===========================
A functional Wordle game built using HTML, CSS, and JavaScript. This implementation is hosted on a local server and utilizes maps for efficient game logic.

Features:
Classic Wordle Gameplay – Guess a hidden word in six attempts.
Color Feedback – Letters change color based on correctness (green, yellow, gray).
Local Server Hosting – Run the game directly from a local server.
Optimized Data Handling – Uses maps for efficient state management.
